## 戦略の結論（30秒版）

1. **ポジショニングを「那智の滝への道沿い、自家源泉を独り占めできる唯一のマンガ温泉ハウス」に再定義する。**「エリア唯一の温泉一棟貸し」という訴求は太地町の競合を考えると危険なので使わない。
2. **最大のレバーはADRではなく閑散期（1・2・6・9・12月）の稼働率。**閑散月は日本人・外国人需要の谷が重なっているので、「谷向けの商品」（連泊割・冬の生マグロ・梅雨の漫画ごもりプラン）を作って埋める。
3. **直販（自社サイト・Google経由）を3年で25%まで引き上げる。**直販は同じ価格でもBooking.com比で1泊あたり約1,800円利益が多い。HPの「予約システム準備中」を最優先で解消する。
4. **連泊を標準にする。**清掃費5,500円は「1組あたり」なので、平均泊数が1.5→2.0泊になるだけで利益率が大きく改善する。ホストも公式に「2泊以上推奨」を謳っており一貫性がある。
5. **値下げ競争はしない。**1泊2名の損益分岐はBooking.com経由で約12,000円。これを下回る集客はどんなに稼働が埋まっても意味がない。
