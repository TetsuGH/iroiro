# 熊野古道 文献データベース

熊野古道ガイドをしている友人の論文執筆を手伝うための、本の抜粋・引用を蓄積するデータベースです。
観光案内ではなく「集めた資料のどこに何が書いてあったか」を検索・比較できるようにすることが目的です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `sources.csv` | 参考文献の一覧（書名・著者・出版社・年・形態など） |
| `excerpts.csv` | 本文からの抜粋・ハイライト（出典・位置・引用文・出典citation・要約・メモ） |
| `images/` | 本のページを撮影・スキャンした画像やPDFの置き場所 |
| `scripts/search.py` | キーワード・タグで抜粋を検索/比較するCLIツール |

## データの入れ方

### 1. 本を `sources.csv` に登録する

1行＝1冊。`source_id` は `S0001`, `S0002`... と連番で振ってください。

### 2. 抜粋を `excerpts.csv` に登録する

1行＝1つの抜粋（複数のKindleハイライトをまとめて再構成したもの）。`source_id` で `sources.csv` の本と紐付けます。

- `location`: ページ数（例 `p.42`）、または Kindle の位置No.（例 `Kindle位置No.58` や、複数ハイライトをまとめた場合は `Kindle位置No.71/76/79/86/90` のように `/` 区切りで元の位置を全部残す）
- `quote`: **ハイライトされた原文をそのまま**つなげたもの（`／`区切り）。Kindleは単語単位の断片ハイライトも多いため、ここは逐語的・verbatimな原文の寄せ集め
- `citation`: その抜粋の範囲内に出てくる史料名・引用文献名（本文中でピンク色でハイライトされていたもの。例: `扶桑略記、栄花物語`）
- `summary`: 複数の断片をつなげて読みやすくした**要約・再構成文**。**これは原文の逐語的な引用ではなく、断片から推測して書いた説明文**なので、論文に直接引用する前に必ず原文（本）で該当箇所を確認してください
- `tags`: （現在は運用していません。空欄のままでOK）
- `note`: 再構成の根拠や、不確かな点・要確認事項など

**重要: `quote`と`summary`の違い**
`quote`列はKindleでハイライトされた文字列そのもの（verbatim）です。`summary`列は、断片同士のつながりをAIが補って書いた説明文で、本の地の文そのものではありません。論文で直接引用する場合は`quote`列（それも元のページ・位置を本で確認した上で）を使い、`summary`は内容を把握するための下書きとして扱ってください。

### 3. 資料の提供方法

以下のいずれかの形でこのセッションに渡してもらえれば、こちらで `excerpts.csv` に落とし込みます。

- **Kindleのハイライト**: [read.amazon.co.jp/notebook](https://read.amazon.co.jp/notebook) で該当の本を開き、ページ全体をコピー＆このチャットに貼り付け。位置Noと色（水色/ピンク）もまとめて取り込みます。
- **本のページの写真・スキャン**: 画像やPDFを `images/` に置くか、このセッションにアップロードしてください。内容を読み取って `excerpts.csv` に書き起こします。

### ふりがな（ルビ）について

Kindleでルビ（ふりがな）が振られていた語は、コピー時に読み（ひらがな）は失われ、文字間に不自然なスペースだけが残ります（例: `大 阿 斗 足尼`）。読み自体は復元できませんが、このスペースは情報として`quote`列にそのまま残しています。

### ハイライトの色について

このデータベースでは次の対応で扱っています（小山靖憲『熊野古道』で確認済み）。

- **水色のハイライト** → 本文の内容（`quote`に採用）
- **ピンクのハイライト** → 本文中に出てくる史料・引用文献名（`citation`に採用）

## 検索・比較の使い方

```bash
# 登録済みの文献一覧
python3 scripts/search.py list-sources

# キーワードで抜粋を検索（原文・出典・要約・メモ・位置情報から検索）
python3 scripts/search.py search 白河

# タグで絞り込み（現在tagsは未運用）
python3 scripts/search.py search --tag 中辺路

# 同じキーワード/タグについて、出典ごとに記述（要約があれば要約）を並べて比較する
python3 scripts/search.py compare 熊野詣
```

CSVファイルなのでExcel/Numbers/Googleスプレッドシートでも直接開いて編集・ソート・フィルタできます。
