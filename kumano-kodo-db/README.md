# 熊野古道 文献データベース

熊野古道ガイドをしている友人の論文執筆を手伝うための、本の抜粋・引用を蓄積するデータベースです。
観光案内ではなく「集めた資料のどこに何が書いてあったか」を検索・比較できるようにすることが目的です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `sources.csv` | 参考文献の一覧（書名・著者・出版社・年・形態など） |
| `excerpts.csv` | 本文からの抜粋・ハイライト（出典・ページ/位置・引用文・タグ・メモ） |
| `images/` | 本のページを撮影・スキャンした画像やPDFの置き場所 |
| `scripts/search.py` | キーワード・タグで抜粋を検索/比較するCLIツール |

`sources.csv` と `excerpts.csv` には記入例の行（`（記入例）`で始まる行）が入っています。
実データを登録したら削除してください。

## データの入れ方

### 1. 本を `sources.csv` に登録する

1行＝1冊。`source_id` は `S0001`, `S0002`... と連番で振ってください。

### 2. 抜粋を `excerpts.csv` に登録する

1行＝1つの抜粋（引用・ハイライト）。`source_id` で `sources.csv` の本と紐付けます。

- `location`: ページ数（例 `p.42`）、または Kindle の位置No.（例 `Kindle位置No.1203`）
- `quote`: 引用文そのもの（できるだけ原文のまま）
- `tags`: キーワードを `|` 区切りで（例 `中辺路|御幸|歴史`）。論文の章立てやテーマに合わせて揃えていくと、後で比較しやすくなります
- `note`: 自分の解釈や、他の資料と比較したい点などの論文用メモ

### 3. 資料の提供方法

以下のいずれかの形でこのセッションに渡してもらえれば、こちらで `excerpts.csv` に落とし込みます。

- **Kindleのハイライト**: [read.amazon.co.jp/notebook](https://read.amazon.co.jp/notebook) で該当の本を開くと、ハイライト一覧をテキストとしてコピーできます。それをそのまま貼り付けてもらえればOKです（位置Noも一緒に表示されます）。
- **本のページの写真・スキャン**: 画像やPDFを `images/` に置くか、このセッションにアップロードしてください。内容を読み取って `excerpts.csv` に書き起こします。

## 検索・比較の使い方

```bash
# 登録済みの文献一覧
python3 scripts/search.py list-sources

# キーワードで抜粋を検索（引用文・タグ・メモ・位置情報から検索）
python3 scripts/search.py search 蟻の熊野詣

# タグで絞り込み
python3 scripts/search.py search --tag 中辺路

# 同じキーワード/タグについて、出典ごとに記述を並べて比較する
python3 scripts/search.py compare 中辺路
```

CSVファイルなのでExcel/Numbers/Googleスプレッドシートでも直接開いて編集・ソート・フィルタできます。

## 今後の進め方（相談ポイント）

- タグの語彙（表記ゆれ: 「中辺路」「中辺路ルート」など）は書きためながら揃えていきます。迷ったら聞いてください。
- データが増えてきたら、章立て（論文の構成）に合わせたタグの整理や、SQLiteへの移行（より複雑な検索をしたくなった場合）も検討できます。
- NotebookLMを併用したい場合、`excerpts.csv` から出典ごとにMarkdownファイルを書き出すスクリプトも追加できます。必要になったら言ってください。
