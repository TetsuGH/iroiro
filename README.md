## 戦略の結論（30秒版）

1. **ポジショニングを「那智の滝への道沿い、自家源泉を独り占めできる唯一のマンガ温泉ハウス」に再定義する。**「エリア唯一の温泉一棟貸し」という訴求は太地町の競合を考えると危険なので使わない。
2. **第一のレバーは閑散期（1・2・6・9・12月）の稼働率。**閑散月は日本人・外国人需要の谷が重なっているので、「谷向けの商品」（連泊割・冬の生マグロ・梅雨の漫画ごもりプラン）を作って埋める。
3. **第二のレバーは単価。AirROI実測で南の湯のADR(20,950円)は一棟貸し34件中16位の「中位」**にすぎない一方、収益は6位・稼働は7位。温泉なし駅近物件が2.4万〜2.8万円×稼働40%超を実証しており、ピーク期(特に一棟貸し市場最大の商戦である11月)の単価テストをYear 1から行う。
4. **直販（自社サイト・Google経由）を3年で25%まで引き上げる。**直販は同じ価格でもBooking.com比で1泊あたり約1,800円利益が多い。HPの「予約システム準備中」を最優先で解消する。
5. **連泊を標準にする。**清掃費5,500円は「1組あたり」なので、平均泊数が1.5→2.0泊になるだけで利益率が大きく改善する。ホストも公式に「2泊以上推奨」を謳っており一貫性がある。
6. **値下げ競争はしない。**1泊2名の損益分岐はBooking.com経由で約12,000円。市場は供給+49%・稼働-9%の二極化が進むが、南の湯は収益96パーセンタイルの「埋まる側」。守るべきは価格ではなく上位ポジション（レビュー・写真・体験価値）。

## 注意（調査の制約）

本調査はネットワーク制限のある環境で実施したため、OTAサイトの**画像・空室カレンダーの直接閲覧はできていません**。
競合の稼働率はレビュー投稿ペースからの推定値です。方法と限界は03のドキュメントに明記しています。
公開前に、お手元のブラウザで各競合のカレンダー・写真を確認する手順も02に含めてあります。

**AirROI実測データ（2026/7/12更新）**: オーナーがブラウザ経由で取得した**那智勝浦市場そのものの全64物件データ**（`data/`フォルダに原本）を反映済みです。
これにより当初の近隣市場による代理ベンチマークは実測値に置き換わりました。主な修正点:
「単価にも伸びしろあり(ADRは市場中位)」「一棟貸し市場のピークは11月」「月別リードタイムに合わせた値下げタイミング」「MaruHouse(稼働74%)を運用ベンチマークに採用」「アメニティ投資の優先順位(乾燥機・出迎え演出など)」。
